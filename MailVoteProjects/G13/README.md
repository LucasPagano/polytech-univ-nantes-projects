Pour utiliser l'API JavaMail : 

1. Mettre le .jar dans le dossier du projet.
2. Dans Eclispe, faire un clic droit sur le nom du projet et cliquer sur Propriétés
3. Dans Java Build Path, cliquer sur l'onglet Libraries 
4. Cliquer sur Add External JARs et ajouter le fichier .jar
5. Mettre dans le FolderFetchIMAP.java votre adresse mail et votre mot de passe

Wiki sur le webmail : http://wiki.univ-nantes.fr/mailunique:documentation:etudiants:releve_exterieur
