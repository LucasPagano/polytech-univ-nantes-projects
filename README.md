# Polytech / Université de Nantes — school projects

Projects migrated from [GitLab univ-nantes](https://gitlab.univ-nantes.fr/E144754R) (account `E144754R`, Polytech Nantes). Commit history from each original repository is preserved.

## Projects

### [`3A/`](./3A) — 3rd year coursework
Coursework and TPs from the 3rd year (display name on GitLab: *3A - third year*; path was `My-awesome-projects`). Covers **C**, **Java**, **Python**, **Prolog**, **R**, **SQL**, **systems**, **networking** (token ring, client/server), and **web**.

### [`4A/`](./4A) — 4th year C++ labs
4th-year **C++** practicals (TP1–TP5): classes, strings, matrices, templates, and related exercises (Visual Studio solutions).

### [`IA-Prolog/`](./IA-Prolog) — AI mini-project (Prolog)
2017–2018 AI mini-project in **Prolog**: A\* search to find a good dimension permutation for multi-dimensional individuals (minimize area), plus a grid-scoring demo and unit tests.

### [`MailVote/`](./MailVote) — email voting system (Java)
Java app that drives an **automatic assignment / voting** flow over an **IMAP** mailbox: initiators create runs and choices, clients vote by email commands (`HELP`, `RUN`, `VOTE`, etc.).

### [`MailVoteProjects/`](./MailVoteProjects) — shared MailVote group submissions
Class dump of other groups’ **MailVote** implementations (G1, G2, G10, G11, …) for the same Polytech specs — useful as reference next to `MailVote/`.

### [`ProjetC/`](./ProjetC) — Dice Wars (C + SDL)
C project: **Dice Wars**–style game with map/graph, dice combat, **SDL** UI, and pluggable **AI** libraries (`.so`). Includes report (`Rapport.pdf`) and sample strategies.
